Guide d’utilisation du catalogue des fiches de données.

Liste et recherche des fiches

  • La liste affiche les fiches de données avec leur donnée métier, ID métier, objet métier, propriétaire, sensibilité, source et date de dernière mise à jour.
  • Utilisez la recherche pour retrouver une fiche par donnée métier ou objet métier. Sélectionnez un résultat pour ouvrir la fiche.
  • Le filtre « Mes données » limite la liste aux fiches du propriétaire sélectionné. « Tous » affiche les fiches disponibles.

Propriétaire et lecture seule

  • Choisissez votre profil Data Steward dans les paramètres. Le propriétaire d’une fiche détermine qui peut la modifier.
  • Seul le propriétaire peut modifier sa fiche. Les autres utilisateurs la consultent en lecture seule ; le bouton devient « Visualiser ».
  • Les modifications sont sauvegardées automatiquement dans le navigateur.

Caractérisation des fiches

  • Complétez les sections Identification, Source, Caractérisation, Sensibilité et Gouvernance.
  • Les champs obligatoires sont signalés par un astérisque. Le compteur de la barre latérale indique les champs obligatoires manquants, puis le total des champs encore vides.
  • Certains champs proposent des choix ou une autocomplétion à partir des valeurs déjà saisies dans les fiches.
  • Une fiche peut être visualisée avant validation. La validation crée une nouvelle version.

Import et export JSON

  • « Exporter » télécharge toutes les fiches du propriétaire sélectionné dans un fichier JSON nommé DS_AAAAMMJJ_HHMM_ACR.json, où ACR est l’acronyme du profil.
  • « Importer » accepte un ou plusieurs fichiers JSON. L’import remplace toutes les fiches existantes du propriétaire et leurs informations ; vérifiez les fichiers avant de confirmer.
  • Conservez les exports comme sauvegardes avant un remplacement par import.
